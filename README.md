# ob-pty

Obsidian のノートにターミナルを埋め込み、そこで実行したコマンドの入出力をコードブロックとしてノートに挿入するプラグイン。macOS / Linux 向け (`isDesktopOnly`)。

- **PTY モード** — プラグインがシェルを起動する。```` ```term zsh /dev/ttys013 ````
- **tmux モード** — 既に動いている tmux ペインに接続する。```` ```term tmux %3 ````

## インストール

```sh
npm i && npm run build                                   # main.js / styles.css を生成
ln -s "$PWD" "/path/to/vault/.obsidian/plugins/ob-pty"   # vault へリンク
```

Obsidian の 設定 → コミュニティプラグイン → 「ob-pty」を有効化。
ビルドし直したら、トグルを OFF/ON するか `Cmd+R` で再読み込みすること。

必要なもの: `python3`（`xcode-select --install` で入る）、tmux モードを使うなら `tmux`。
GUI 起動の Obsidian は PATH が `/usr/bin:/bin:/usr/sbin:/sbin` しか無いので、
子プロセスには `/opt/homebrew/bin` と `/usr/local/bin` を足した PATH を渡している。
別の場所に入れている場合は `main.ts` の `ENV` を直す。

## 使い方 (PTY モード)

### 1. ターミナルを置く

ノートを開き、置きたい場所にカーソルを合わせて次のどちらかを実行する。

- 左のリボンの端末アイコン
- コマンドパレット (`Cmd+P`) → **「ターミナルを挿入」**

`$SHELL` でシェルが起動し、カーソル位置にブロックが挿入される。

````
```term zsh /dev/ttys013
```
````

`/dev/ttys013` が今起動した PTY のパス。この行がセッションの住所になる。

### 2. 使う

ブロックはそのままターミナルとして描画される（読み取りビュー・ライブプレビューのどちらでも）。クリックしてそのまま打てばよい。vim や top のような TUI も動く。

ヘッダの中身:

| 表示 | 意味 |
|---|---|
| `/dev/ttys013` | 接続先。tmux モードなら `tmux %3` |
| プルダウン | このセッションで実行したコマンドの履歴。`1: ls -la` のように並び、新しいものが自動で選択される |
| 「挿入」 | 選択中のコマンドの入出力を、**このブロックの直下**に挿入する |
| 「ノート」 | 前回のノート以降の出力をまとめて、**本文の末尾**に追記する |
| 「終了」 | シェルを kill する（tmux モードでは「切断」） |

ターミナルの枠は右下をドラッグして高さを変えられる。幅・高さに合わせて `stty` で
winsize が追従するので、TUI の表示も崩れない。

### 3. コマンドをノートに挿入する

プルダウンでコマンドを選んで「挿入」を押すと、**そのターミナルブロックの直下**に挿入される。

````
```zsh
% ls -la
total 8
drwxr-xr-x  3 r  staff  96 Nov  7 08:12 .
```
````

- プロンプト (PS1) は落とす。コマンド行だけ zsh なら `% `、それ以外は `$ ` を付ける。
- フェンスの言語は挿入時に `ps` でそのターミナルを見て決まる。`exec bash` した後なら `bash` になる。
- **コマンドが終わるのを待たなくてよい**。実行中に挿入すると、その時点までの出力が入る
  （`npm install` の途中経過や、改行していない進捗行もそのまま）。終わってからもう一度挿入すれば全体が入る。
- 続けて挿入すると、前に挿入したコードブロックの**下に順に積まれる**（上書きや逆順にはならない）。
- 色やエスケープシーケンスは除去済みのプレーンテキストが入る。

### 「ノート」ボタン

コマンド単位ではなく、ターミナルの流れをそのまま残したいとき用。押すと
**前回押した位置から今まで**の出力がノート本文の末尾にコードブロックで追記される
（初回はセッション開始から全部）。プロンプト行もそのまま入るので、作業ログになる。

`docker run` や `tail -f` のように終わらないコマンドや、対話的に何度もやり取りした
セッションは、コマンド単位の「挿入」より扱いやすい。押すたびに続きだけが追記される。

## 使い方 (tmux モード)

既に作業中のターミナルをノートに引き込みたいときはこちら。

1. コマンドパレット → **「tmux ペインを挿入」**
2. ペインの一覧が出るので選ぶ（`%3 work:1.0 [vim]` のような表示）
3. ブロックが挿入される

````
```term tmux %3
```
````

4. 「接続」を押すと、そのペインの現在の画面がノートに出る。**読み書きどちらもできる** ので、
   iTerm 側で打っても Obsidian 側で打っても同じペインが動く。

- サイズは tmux のペインに合わせる（ノート側ではリサイズしない）。
- 「切断」で pipe-pane を外すだけ。ペインもシェルも残る。
- ペイン ID は `tmux list-panes -a -F '#{pane_id} #{pane_current_command}'` でも調べられる。

## ブロックを手で書く

フェンス行の書式は ```` ```term <引数...> ````。引数は順不同で、本文側に書いてもよい。

| 書き方 | 動作 |
|---|---|
| ```` ```term zsh /dev/ttys013 ```` | その PTY に接続。無ければ「起動」ボタン |
| ```` ```term bash ```` | 「起動」で bash を起動し、パスを書き戻す |
| ```` ```term ```` | 「起動」で `$SHELL` を起動し、パスを書き戻す |
| ```` ```term tmux %3 ```` | tmux ペイン %3 に「接続」 |

- 同じ PTY パスのブロックを別のノートに書けば、同じセッションを共有できる。
- Obsidian を再起動するとセッションは消えるので、ブロックは「未接続」表示に戻る。
  「起動」を押すと新しいシェルが起動し、フェンス行のパスがそこに書き換わる。
- Obsidian 終了時に、プラグインが起動したシェルは全部 kill される（tmux ペインは残る）。

## しくみ

- PTY は `python3 -c 'import pty; pty.spawn(...)'` で確保する（ネイティブモジュール不要）。
  macOS の `script(1)` は stdin が tty でないと `tcgetattr` で落ちるため使えない。
- slave デバイス名は子シェルの `tty` を一時ファイルに書かせて取得。これが `{pty_path}`。
- リサイズは `stty -f <pty_path> rows R cols C`（SIGWINCH も飛ぶ）。
- 挿入時に `ps -t <tty> -o stat=,comm=` を 1 回だけ引き、シェル名（最も内側のシェル）と
  実行中かどうか（前景プロセスグループ `+` がシェル自身かどうか）を同時に判定する。
  実行中なら末尾の書きかけの行も出力として残し、完了後ならプロンプトとみなして落とす。
- tmux モードは出力を `pipe-pane -t %3 'cat >> file'` + `tail -f`、入力を `send-keys -t %3 -H <hex>` で流す。
  接続前の画面は `capture-pane -p -e` で一度だけ流し込む。
- 入出力は生ログで全部保持。Enter 押下時の xterm バッファ上のカーソル位置を PS1 幅とみなし、
  そこから入力本体を切り出す（履歴呼び出し・補完・BS すべて正しく取れる）。
  位置は「折り返しを連結した論理行の先頭からのオフセット」で持ち、行の取得には `baseY + cursorY`
  を使う。これを怠るとスクロール後に過去の行を読み、長いコマンドは折り返しで取りこぼす
  （`log.ts` の `cursorLine` と `test.mjs` の回帰テスト）。
- 出力は「次の Enter までの生ログ」から ANSI を除去し、末尾の改行で終わっていない行（= 次のプロンプト）を落とす。

## 制限

- `python3` が必要（Xcode CLT か Homebrew）。
- 素の tty（iTerm 等）には接続できない。slave を read すると本来のシェルから入力を奪い、
  write しても画面に文字が描かれるだけで実行されないため。既存セッションに入りたい場合は tmux モードを使う。
- tmux モードでは、ペインを閉じても `tail` が残る（「切断」を押せば片付く）。
- vim 等の TUI 中の Enter もコマンドとして記録されることがある。
- 改行で終わらない出力（`printf abc`）は最終行がプロンプトと一緒に落ちる。
- 行が折り返すほど長いコマンドは、挿入時に末尾だけになることがある。
